종료 이벤트도 기록됐다. 분석기의 잘못된 레코드는 0개였다.
이후 기존 자동 재접속 시도도 별도 attempt로 구분됐다.

## 한계 및 변경 범위

실제 Mac 호스트 인증, 첫 영상 표시, 코덱·FPS·영상 전송량,
Tailscale 직접/중계 경로와 4G 지연은 검증하지 않았다.
이번 시험 서버는 정상 인증이나 영상 스트리밍을 구현하지 않는다.

별도로 시도한 Mac 로컬 네이티브 빌드는 설치 후 libsodium 심볼 누락으로
실행되지 않았다. 이 로컬 산출물은 전달용 APK로 사용하지 않았다.
로컬 빌드를 재시도할 때에는 암호화 심볼 링크를 먼저 확인해야 한다.

이번 검증 커밋은 기록을 갱신하고 다운로드 장애 때 추가했던 임시 복구
워크플로만 제거한다. 빌드 중 사용한 Gradle 경로 우회는 되돌렸으며,
기존 앱 소스와 런타임 실행 경로에는 추가 변경이 없다.
